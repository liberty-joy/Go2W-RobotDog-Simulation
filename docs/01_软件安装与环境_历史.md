安装目录：`/home/joy/robotics`。

- Isaac Sim 6.2.0.0，完整功能包与扩展缓存：`/home/joy/robotics/isaac-env`
- Isaac Lab 3.0.0，训练框架、Newton、OV PhysX/RTX 和可视化依赖：`/home/joy/robotics/isaaclab-env`
- 官方源码：`/home/joy/robotics/IsaacLab-source`（按需检出 source/scripts/apps/tools）

启动 Isaac Sim：

```bash
/home/joy/robotics/bin/isaac-sim
```

查看 Isaac Lab 命令：

```bash
/home/joy/robotics/bin/isaac-lab --help
```

进入训练 Python 环境：

```bash
source /home/joy/robotics/isaaclab-env/bin/activate
```

系统依赖与驱动（需要本机管理员密码）：

```bash
sudo apt update
sudo apt install nvidia-driver-595-open python3.12-dev libgl1-mesa-dev libx11-dev libxcursor-dev libxi-dev libxinerama-dev libxrandr-dev
```

驱动 595.99.02 和上述系统依赖已安装；需要重启使新驱动生效。重启前保存其他工作。

完整功能包包含 ROS 2 Bridge；独立 ROS 2 工作空间、Isaac ROS、Go2W 机器人资产与控制任务留待需求确定后配置。场景和机器人在线资产按需下载，此次不镜像整个资产库。

## 安装与验证记录（2026-10-25）

- Isaac Sim 6.2.0.0、Isaac Lab 3.0.0 均已安装。Sim 运行时版本字符串为 6.2.0-rc.14。
- 两个环境均使用 Python 3.12、PyTorch 2.11.0 / CUDA 13.0、Warp 1.17.0。
- 两个环境的 RTX 5090 GPU 张量计算均通过。
- Isaac Sim 无窗口启动、场景创建和更新通过（`ISAAC_SIM_SMOKE_OK`）。
- Isaac Lab GPU PhysX 20 步仿真通过（`ISAAC_LAB_PHYSX_SMOKE_OK`）。
- Newton、RSL-RL、Stable Baselines3、SKRL 导入通过。
- 官方源码 v3.0.0 已检出运行所需的 source/scripts/apps/tools，未修改源码。
- 图形界面启动发现 Kit 扩展与 pip 字符编码库混合导入问题；启动器先加载 pip 库以修正导入顺序。
- 图形界面最终复查待重启：驱动升级期间运行库已更新到 595，但内核驱动仍为 580，当前 `nvidia-smi` 会报告驱动与库不匹配。
