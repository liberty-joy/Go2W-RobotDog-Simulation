# Go2W 轮腿策略分项评估

> 文档导航：编号与复现入口见 [00_复现总览与文档索引](00_复现总览与文档索引.md)。本文保留历史记录或规划，不代表本次复验结果；本次结果以 [阶段0环境验收](sensor_pipeline/00_environment.md) 为准。

**评估修正：本文件下方的旧版 9/10 结果及最初对比图混入了 12 秒回合超时重置，已不作为验收结论。** 修正后的完整连续测试为 10/10 通过，详见 [鲁棒训练与模式切换](Go2W鲁棒训练与模式切换.md)。当前脚本默认应用与部署一致的停车残差缩放，报告明确记录 `stop_gate`，可用 `--raw-residuals` 单独测试未缩放策略。

本阶段先验证平地轮式移动与腿部姿态控制。腿部输出为站姿附近的残差，不代表已经学会抬腿越障或复杂地形步态。

## 测试方法

8 个并行环境，种子 42。每项运行 180 个控制步（6 秒仿真时间），前 1 秒用于指令切换，后 5 秒统计速度误差。所有控制步均统计提前重置。10 项连续执行，保留前一个动作的物理状态，用于检验停车与换向。

测试顺序：静止、前进、前进后停车、后退、后退后停车、左转、右转、左弧线、右弧线、最后停车。前进 0.15m/s，后退 −0.10m/s，转向 ±0.30rad/s。

当前工程验收阈值：平均平面速度误差 <0.06m/s，平均转向角速度误差 <0.15rad/s，平均直立度 >0.98，统计区间最小机身高度 >0.30m，提前重置为 0；停车还要求统计区间所有环境的峰值平面速度 <0.05m/s。这些是本项目的初始阈值，不能等同于产品认证标准。

这里测试原始训练策略，**没有调用 ROS 场景的零指令制动覆盖**。因此原始策略的停车结果和交互场景可能不同。

## 后续顺序

1. 先让平地轮腿控制在停车、换向、转弯时稳定，并保存验收结果。
2. 加入摩擦、质量、初始姿态、控制延迟变化和小扰动，测试稳定范围。
3. 再加入低坡和小障碍的课程训练，检查是否确实使用腿部调整。
4. 之后单独强化纯腿步态，再处理模式切换。

目前单一种子、固定平地的通过结果不能说明复杂地形或实机适用性。

## 本次结果（2026-10-25）

从原 300 轮权重继续训练 300 轮，256 环境，每轮 24 步，新增 1,843,200 条环境转移。新权重保存在 `outputs/training/wheel_flat_continued`，导出网络与原网络输出一致性检查通过。

| 指标（10 项等权平均） | 初始策略 | 继续训练后 |
|---|---|---|
| 平面速度误差 | 0.02534m/s | 0.01795m/s |
| 转向角速度误差 | 0.05012rad/s | 0.04067rad/s |
| 提前重置次数 | 0 | 0 |
| 分项通过数 | 9/10 | 9/10 |
| 最后停车阶段的峰值平面速度 | 0.08917m/s | 0.09011m/s |

整体平均速度误差改善约 29.2%，转向误差改善约 18.8%；左原地转向的误差略增加，不能声称所有转向都改善。最后停车的瞬时峰值仍超过 0.05m/s，所以**原始策略尚未全部达标**。当前 ROS 控制器的零指令制动仍需保留；没有自动替换正在运行的交互场景策略。

图表：`outputs/training/wheel_policy_comparison.png`。图中只比较平均跟踪误差，停车峰值是否通过应看上表及 JSON。

新权重另在 ROS_DOMAIN_ID=43 中完成独立进程联调，8 项检查全部通过：指令驱动、过期制动、RGB 图像、内参、关节、TF、相机 optical TF、仿真时钟。过期制动后平面速度 0.01571m/s；4.467 秒仿真时间对应 4.513 秒墙钟时间。报告为 `outputs/ros2/verification-continued-policy.json`。这项测试包含运行时制动覆盖，不能替代上面的原始策略停车测试。
